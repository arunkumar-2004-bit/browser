      Under the hood

      How It Works

      01

      Page Fetched

      The URL is fetched via a CORS proxy. The raw HTML is returned without executing JavaScript — a safe, sandboxed snapshot.

      02

      Resources Parsed

      Every script src, iframe, image, link, and inline URL is extracted and its domain catalogued — hundreds of resources per page.

      03

      Blocklist Matched

      Each domain is checked against 200+ known ad networks, trackers, session replay tools, DMPs, and fingerprinters.

      04

      Cosmetic Filter

      40+ CSS selectors are injected to hide ad containers, banners, popups, and overlays from the rendered page.

      05

      Browser Loads

      The cleaned URL loads inside our built-in browser with ad globals nulled, referrers stripped, and cookies blocked.

      06

      Report Generated

      Full transparency: every blocked domain is listed with its name, category, and risk level so you know what was hiding.

      Technical deep-dive

      Blocking Techniques

      🔗

      URL / Network Filtering

      Every outgoing request domain is matched against EasyList, EasyPrivacy, and uBlock Origin filter rules. Matches are dropped before bytes hit the wire.

      Blocklist domain match + fetch intercept
      🧹

      DOM Cosmetic Filtering

      CSS selectors from EasyList cosmetic rules hide or remove ad containers, sticky banners, and popups from the rendered DOM tree.

      querySelectorAll + display:none !important
      🍪

      Cookie & Storage Blocking

      Third-party cookies, localStorage trackers, IndexedDB fingerprints, and evercookies are blocked via SameSite enforcement and Storage Access API restrictions.

      SameSite=Strict + StorageAccess API deny
      🔍

      DNS-over-HTTPS (DoH)

      DNS queries routed over HTTPS prevent ISPs and upstream resolvers from seeing which domains you look up — used by Brave, Firefox, and Chrome.

      Cloudflare / Google DoH endpoints
      🧠

      Fingerprint Randomization

      Canvas, WebGL, AudioContext, font enumeration, screen.colorDepth, and navigator APIs return subtly randomized values to prevent cross-site identity linking.

      API override + canvas noise injection
      📡

      CNAME Tracking Uncloaking

      Trackers disguise as first-party domains via CNAME DNS delegation. We resolve CNAME chains server-side and compare the real IPs against blocklists.

      DNS CNAME resolution + blocklist match
      🛑

      Script Global Nulling

      Before page scripts run, ad globals (googletag, ga, fbq, gtag, dataLayer) are replaced with no-ops so ad infrastructure can't initialize.

      window.googletag = no-op stub
      🔒

      Referrer Policy Enforcement

      The Referrer header is trimmed to origin-only or stripped entirely, preventing cross-site URL leakage that ad networks use to build browsing profiles.

      Referrer-Policy: strict-origin
