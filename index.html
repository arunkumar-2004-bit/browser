      Under the hood

      How It Works

      01

      URL Parsed

      The domain is extracted and matched against curated blocklists (EasyList, EasyPrivacy, uBlock Origin filters).

      02

      DNS Lookup Blocked

      Known ad/tracker domains are intercepted at the network layer before any request is made.

      03

      Script Injection

      A content script removes DOM elements matching ad selectors (div[class*="ad"], iframes, overlays).

      04

      Report Generated

      All blocked resources are logged and shown to you — full transparency on what was hiding.

      Technical deep-dive

      Blocking Techniques

      🔗

      URL / Network Filtering

      Requests to known ad/tracker domains (doubleclick.net, googlesyndication.com, etc.) are blocked before they reach the network using a blocklist lookup.

      Fetch/XHR intercept + blocklist matching
      🧹

      DOM Cosmetic Filtering

      CSS selectors from EasyList cosmetic filters hide or remove ad containers, sticky banners, and popups from the rendered page.

      document.querySelectorAll + display:none
      🍪

      Cookie & Storage Blocking

      Third-party cookies, localStorage trackers, and fingerprinting scripts are prevented from running via script sandboxing.

      SameSite=Strict + StorageAccess API
      🔍

      DNS-over-HTTPS (DoH)

      Routing DNS queries over HTTPS prevents ISPs and trackers from seeing which domains you resolve — used by Brave & Firefox.

      Cloudflare / Google DoH endpoints
      🧠

      Fingerprint Randomization

      Canvas, WebGL, AudioContext, and font fingerprinting APIs return randomized values to prevent cross-site tracking without cookies.

      navigator override + canvas noise injection
      📡

      CNAME Tracking Uncloaking

      Trackers disguise themselves as first-party via CNAME DNS records. We resolve CNAMEs and compare against blocklists to catch these.

      DNS CNAME resolution + blocklist match
      Deploy it yourself

      Host on GitHub Pages

      1

      Create a GitHub Repo

      Go to github.com → New Repository → name it quit-the-distracts → Public → Create.

      2

      Upload the Files

      Upload index.html, style.css, app.js, and blocklist.js to the repo root.

      3

      Enable GitHub Pages

      Settings → Pages → Source: Deploy from branch → Branch: main / / (root) → Save.

      4

      Your Site is Live

      Visit https://yourusername.github.io/quit-the-distracts — it's live and free forever.

      5

      Optional: Custom Domain

      Add a CNAME file with your domain name, then configure DNS records with your registrar. GitHub handles HTTPS automatically.

      ⚠️ About the Proxy: Full ad-removal from live pages requires a server-side proxy (e.g., Cloudflare Workers, Vercel Edge, or Node.js). The scan/report feature works entirely in the browser. For the cleaned preview, deploy proxy.js to Vercel or Cloudflare Workers and update the PROXY_URL in app.js.
